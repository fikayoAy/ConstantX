# ConstantX VS Code Extension

VS Code admin layer for ConstantX. It starts the shared HTTP MCP runtime, generates provider MCP config snippets, opens workflow prompts, and shows a styled status panel for runs, jobs, logs, verification files, and patches.

## Commands

- ConstantX: First Run Setup
- ConstantX: Start Runtime
- ConstantX: Stop Runtime
- ConstantX: Check Runtime
- ConstantX: Health Check
- ConstantX: Connect Provider
- ConstantX: Open Workflow Prompts
- ConstantX: Open Status Panel
